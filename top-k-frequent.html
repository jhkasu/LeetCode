Top K Frequent Elements

Bucket sort · O(n) time · O(n) space · all problems

Idea. Use the frequency as the index. bucket[3] holds every number that appears 3 times.

A number can appear at most len(nums) times, so len(nums) + 1 buckets is enough. No sorting needed: higher index already means higher frequency.

Each bucket is a list, because several numbers can share the same frequency.
