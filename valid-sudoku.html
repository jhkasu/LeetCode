Valid Sudoku

Hash sets · O(81) time · all problems

Idea. Walk every cell. Keep one set per row, one set per column, one set per 3×3 square. Before adding a digit, check whether it is already in the set for that row, column, or square. If yes → not valid.

Which square a cell belongs to: (r // 3, c // 3). Integer division turns rows 0,1,2 → 0, rows 3,4,5 → 1, rows 6,7,8 → 2. Same for columns.

defaultdict(set): a dictionary that creates an empty set automatically the first time a key is used, so rows[r] never raises KeyError.
