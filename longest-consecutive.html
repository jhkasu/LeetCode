Longest Consecutive Sequence

Hash set · O(n) time · O(n) space · all problems

Idea. A number is the start of a sequence only if num - 1 is not in the set. Only start counting from starts. Then walk forward: num+1, num+2, ... while each is in the set.

Numbers that are not starts (4, 3, 2 in the example) are skipped, so every number is walked over at most once → O(n) total even with the nested while.

set(nums): removes duplicates and makes x in numSet O(1).
