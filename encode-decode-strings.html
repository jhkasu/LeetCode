Encode and Decode Strings

Length prefix + delimiter · O(n) time · all problems

Encode. For each string write length + '#' + string. ["Hello","World"] → "5#Hello5#World".

Decode. Two pointers. i marks where the current chunk starts. j walks forward to find '#'. The digits between i and j are the length. Then jump exactly that many characters to cut out the string.

The '#' is safe even if a string contains '#', because we never search for '#' inside a string — we jump over it by length.
